# Higher-Lower Game

A console-based implementation of the popular Higher-Lower game, where players guess which entity has a higher value based on given attributes.

## Overview

The Higher-Lower Game is a Python-based console application that challenges players to compare two entities and guess which one has a higher specified attribute. The game continues until the player makes an incorrect guess, aiming to achieve the highest possible score.

## How to Play

1. **Start the Game**: Run the `game.py` script to initiate the game.
2. **View Entities**: Two entities will be presented, each with a specific attribute value (e.g., follower count, popularity).
3. **Make a Guess**: Decide which entity has the higher attribute value and input your choice.
4. **Receive Feedback**: The game will inform you if your guess was correct and update your score accordingly.
5. **Continue or End**: The game continues with new comparisons until an incorrect guess is made, at which point the final score is displayed.

## Technologies Used

- **Python**: Core programming language for the game's logic and functionality.

## Lessons Learned

Developing this project provided valuable insights into:

- **Data Handling**: Efficiently managing and comparing data between different entities.
- **Game Logic Implementation**: Designing a seamless flow for user interactions and game progression.
- **User Input Validation**: Ensuring robust handling of user inputs to maintain game integrity.
- **Modular Programming**: Structuring code into modules (`game.py`, `game_data.py`, `logo.py`) for better organization and maintainability.
